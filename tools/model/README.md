# Игровая версия болида из полной модели Lumen

`make_game.mjs` делает `public/models/f1.glb` из полной модели (сейчас — `/Volumes/I/болид/SF26_доработка.glb`, 70 МБ, ~960 тыс. треугольников):

1. убирает студию Lumen (пол, контактные тени, свет);
2. корень → `car_root`; материалы под код игры: `paint` (красный без текстуры: зеркала, накладки), `paint_livery` (ливрея-текстура: красный кузов, белый овал с окантовкой — перекрашивает `car.js` `recolorLivery`), `paint_secondary`, `accent_blue`, `light_rear` (кольцо светодиодов, линза, светодиоды на торцах крыла);
3. колёса — из прошлой игровой версии (по 8,7 тыс. треугольников, `tyre_sidewall_soft` для цвета состава, `brake_disc` для свечения); центры колёс проверяются;
4. `drs_flap` — верхний закрылок с шарниром у задней кромки, `cam_onboard` — (0; 0,86; 0,10);
5. детали внутри узлов, которые знает код (`body`, `front_wing`, `rear_wing`, `sidepods_engine_cover`, `floor_diffuser`, `caliper_XX`…), сливаются по материалам — меньше вызовов отрисовки;
6. упрощение meshoptimizer с одинаковой ошибкой в метрах (~1 мм), текстуры → WebP до 1024 px.

Запуск (нужны `@gltf-transform/core|extensions|functions@4`, `meshoptimizer`, `sharp`, `gl-matrix` — ставить во временную папку):

    node make_game.mjs <полная.glb> <прошлая игровая.glb — колёса> public/models/f1.glb 0.0004

Последний аргумент — ошибка упрощения (доля ~2,75 м): меньше — детальнее и тяжелее. 30.10: 3,3 МБ, 52,6 тыс. треугольников, 162 вызова отрисовки без наклеек (прошлая — 208).
`glbinfo.mjs`, `mats.mjs`, `prims.mjs` — сводка по файлу: дерево узлов, материалы, вызовы отрисовки.
