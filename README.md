# f1-race

Браузерная 3D-гонка Формулы-1: болид с открытыми колёсами, трасса LUMEN RING (3,7 км), 11 ботов, правила F1, износ шин, поломки и пит-стопы. Three.js + Rapier + Vite, только клиент.

```
npm install
npm run dev
```

Откройте адрес из консоли (в превью prog — http://localhost:5183). Плоская тестовая трасса — `?track=test`.

`npm test` — 61 проверка физики и правил без браузера (`tests/physics.mjs`).

## Что есть

- **Физика болида:** своя подвеска (пружины, стабилизаторы, развал, схождение, клиренс), шина по формуле Пацейки, круг трения, дифференциал, давление шин, граунд-эффект, днище.
- **Трасса и круги:** стены, поребрики, зоны безопасности, пит-лейн; круги, три сектора, дельта к лучшему кругу, мини-карта.
- **Правила F1:** старт по пяти огням, границы трассы (3 предупреждения, дальше +5 с), активная аэродинамика 2026 только в зонах прямой, режим обгона («нитро»), режимы батареи, ABS по желанию игрока.
- **Гонка с ботами:** 5 кругов, 11 соперников на той же физике (лёгкие / средние / сложные), каждый старт решётка и пилоты новые; таблица позиций, экран результатов.
- **Износ и пит-стопы:** три состава шин (износ, температура, прокол), удары ломают крылья, днище, подвеску; силовая установка изнашивается между гонками; пит-стоп как в F1 25, правило двух составов.
- **Гараж (G):** 6 вкладок как в F1 25, готовые пресеты и «Мои настройки», у каждого параметра объяснение для новичка.
- **Звук:** настоящая запись мотора (CC-BY 3.0, автор в `public/sounds/CREDITS.md` — указывать в титрах).

## Управление

Только клавиатура и мышь. Геймпад и рули не поддерживаются. Полный список — в игре: Esc → «Управление».

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, на месте — задний ход |
| A D / ← → | руль |
| Пробел | ручник |
| Shift | режим обгона («нитро»), пока держишь |
| 1 2 3 4 | режим батареи: зарядка, баланс, быстрый круг, обгон |
| F | режим прямой (только в зелёных зонах карты) |
| B | ABS вкл/выкл |
| [ ] | баланс тормозов |
| − = | дифференциал |
| I / K | пит-стоп: состав шин / менять ли переднее крыло |
| Esc | меню паузы |
| G | настройка болида |
| N | новый старт с решётки |
| R | вернуться на трассу |
| C | камера: сзади / из кабины |
| T | телеметрия |
| M | звук вкл/выкл |
| P | цвет болида |

## Устройство

Ощущение руля — числа в `src/tuning.js`. Игрок, бот и (в будущем) удалённый игрок — один «водитель»: набор `{throttle, brake, steer, …}` → физика. Подробности по каждому файлу и принятые решения — в `CLAUDE.md`.

Модели (`public/models/f1.glb` — болид, `track.glb` — трасса) делает отдельная ИИ по ТЗ; болид будет заменён новой версией.
