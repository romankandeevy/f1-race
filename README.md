# f1-race

Браузерная 3D-гонка Формулы-1: Ferrari SF-26 с колёсами пяти составов, городская трасса Marina Bay (Сингапур, 4,94 км), 11 ботов, правила F1, износ шин, поломки, пит-стопы, флаги и машина безопасности, дождь. Three.js + Rapier + Vite, только клиент.

```
npm install
npm run dev
```

Откройте адрес из консоли (в превью prog — http://localhost:5183). Прежняя трасса LUMEN RING — `?track=lumen`, плоская тестовая — `?track=test`.

`npm test` — 116 проверок физики и правил без браузера (`tests/physics.mjs`, считают на LUMEN RING).

## Что есть

- **Главное меню:** гонка, заезд на время, гараж (команды и цвета), настройка болида, рекорды, настройки (графика, звук, мышь, камера, интерфейс), управление.
- **Физика болида:** своя подвеска (пружины, стабилизаторы, развал, схождение, клиренс), шина по формуле Пацейки, круг трения, дифференциал, давление шин, граунд-эффект, днище, топливо как масса.
- **Трасса и круги:** Marina Bay — пока асфальт, пит-лейн, разметка и поребрики (окружение будет); круги, три сектора, дельта к лучшему кругу, мини-карта, призрак лучшего круга.
- **Правила F1:** старт по пяти огням, границы трассы (3 предупреждения, дальше +5 с), активная аэродинамика 2026 в зонах прямой, режим обгона («нитро»), режимы батареи, ABS по желанию, правило двух составов (гонка от 5 кругов), квалификация.
- **Гонка с ботами:** 1–20 кругов, 11 соперников на той же физике (лёгкие / средние / сложные), у каждого свой темп и манера; таблица позиций, итоги.
- **Износ, поломки, пит-стопы:** пять составов шин (износ, температура, прокол), тормоза греются, удары ломают крылья, днище, бокподы, подвеску, монокок; сход; пит-стоп по L — автопилот заводит в бокс, шины и ремонт на выбор.
- **Флаги:** жёлтые, машина безопасности, VSC, красный флаг с рестартом с решётки, эвакуатор с краном.
- **Погода:** дождь со старта или посреди гонки, мокрая трасса, промежуточные и дождевые шины.
- **Звук:** мотор из физического симулятора engine-sim (три на выбор), шины, удары, соперники в пространстве; источники — `public/sounds/CREDITS.md`.
- **Камеры:** сзади, из кабины, T-камера, нос; зеркала заднего вида работают.

## Управление

Только клавиатура и мышь. Геймпад и рули не поддерживаются. Полный список — в игре: Esc → «Управление».

| Клавиша | Действие |
|---|---|
| W | газ |
| S | тормоз, на месте — задний ход |
| A D | руль |
| Пробел | ручник |
| Shift | режим обгона («нитро»), пока держишь |
| 1 2 3 4 | режим батареи: зарядка, баланс, быстрый круг, обгон |
| F | режим прямой (только в зелёных зонах карты) |
| B | ABS вкл/выкл |
| [ ] | баланс тормозов |
| − = | дифференциал |
| L | заехать в боксы (автопилот), повторно — отмена |
| I / K | пит-стоп: состав шин / ремонт кузова |
| Esc | меню паузы |
| G | настройка болида |
| N | новый старт с решётки |
| R | вернуться на трассу |
| C | камера: сзади, из кабины, T-камера, нос |
| ← → ↓, мышь | посмотреть по сторонам / облёт вокруг болида |
| T | телеметрия |
| M | звук вкл/выкл |
| P | цвет болида |

## Устройство

Ощущение руля — числа в `src/tuning.js`. Игрок, бот и (в будущем) удалённый игрок — один «водитель»: набор `{throttle, brake, steer, …}` → физика. Подробности по каждому файлу и принятые решения — в `CLAUDE.md`.

Модели: `public/models/f1.glb` — болид (игровая версия из полной модели, `tools/model/make_game.mjs`), `wheels.glb` — колёса и шины пяти составов (`tools/model/make_wheels.mjs`), `marina.glb` — трасса Marina Bay (делает отдельный агент по ТЗ, проверка — `tools/model/fix_marina.mjs`, `tools/track/lap.mjs`), `track.glb` — прежняя LUMEN RING.
