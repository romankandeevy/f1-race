# f1-race

Браузерная 3D-гонка Формулы-1. Сейчас: тестовая сцена, плоская трасса, один болид, физика и камеры.

```
npm install
npm run dev
```

Откройте адрес из консоли (в превью prog — http://localhost:5183). Плоская тестовая трасса — http://localhost:5183/?track=test.

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, на месте — задний ход |
| Пробел | ручник (блокирует задние колёса) |
| A D / ← → | руль |
| F | заднее крыло (DRS) |
| C | камера: сзади / из кабины |
| R | вернуться на трассу |
| P | сменить цвет краски |
| T | телеметрия |
| G | настройки болида (или кнопка мышью) |
| M | звук вкл/выкл |
| H | панель с клавишами (или «?» слева внизу) |

Звук мотора — запись «Car Engine Loop 96kHz 4s» (qubodup, CC-BY 3.0), подробности в `public/sounds/CREDITS.md`.

Ощущение руля настраивается в `src/tuning.js`, проверка физики — `npm test`. Подробности — в `CLAUDE.md`.
